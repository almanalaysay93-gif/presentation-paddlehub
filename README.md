# PaddleBase 3D Presentation Deck

Interactive 3D presentation deck for paddlebase.org and paddlebaseowner.org.

Built with React 19, Vite, Tailwind CSS v4, Lucide icons, and Framer Motion.

## Features

- 3D spatial perspective mouse tilt with athletic court grid lines
- 7 comprehensive presentation pillars covering ecosystem architecture, player booking, owner POS, digital queue boards, coaching roster, community marketplace, and ASEAN expansion thesis
- 6 native local explainer video reels with autoplay card loops
- Fullscreen video theater modal with playback controls and audio
- Keyboard navigation (Arrow keys, Space, Tab, F, Home, End, Esc)
- Slide jump drawer and telemetry HUD
- AI discoverability via public/llms.txt

## Quick Start

1. Install dependencies:
```bash
pnpm install
```

2. Start local development server:
```bash
pnpm dev
```

3. Build production bundle:
```bash
pnpm build
```

## Deployment

Deployable as a static single page application to Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
No backend or database credentials required.
